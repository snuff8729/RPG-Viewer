# 실제 게임 확인 체크리스트

크롬/엣지에서 게임 폴더를 열고(쓰기 권한 허용) 확인합니다.

## 설치 / 제거
- [ ] 상단 `플러그인 미설치` → 설치 후 게임이 정상 실행된다
- [ ] 제거 후에도 게임이 정상 실행된다 (`rpg-viewer/`와 `plugins.js.bak`은 남는다)
- [ ] 압축 포장된 게임은 `지원하지 않아요`가 표시된다

## 기록
- [ ] 새 게임 시작 → 1회차 갈래 1이 생긴다
- [ ] 대사가 기록에 쌓이고, 탐색기에 본 항목 체크 표시가 붙는다
- [ ] 선택지를 고르면 해당 분기에 Badge가 붙는다
- [ ] 세이브 후 다른 선택을 하면 갈래 2가 생기고 `갈래 2개 ⇄`가 표시된다
- [ ] 게임을 재시작해 세이브를 불러오면 기록이 이어진다

## 실시간 (게임이 실행 중이고 연결된 동안에만 나타남)
- [ ] 사이드바에 "지금" 그룹이 나타난다
- [ ] 조건 ✓/✗가 현재 상태에 맞게 표시된다
- [ ] 지금 선택지 카드가 표시된다
- [ ] 상단 배지가 `● 연결됨`이다

## 못 본 것
- [ ] 목록 정렬이 동작한다
- [ ] 필터가 동작한다

## 종료
- [ ] 게임을 끄면 배지가 `○ 게임 꺼짐 · 마지막 기록 …`으로 바뀌고 "지금" 그룹과 조건 ✓/✗가 사라진다
