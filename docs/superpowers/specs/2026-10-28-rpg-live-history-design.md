# RPG Viewer — 2단계: 실시간 상호작용 + 플레이 기록 설계

작성일: 2026-10-28
선행: `2026-10-28-rpg-explorer-design.md` (1단계 전체 탐색기)

## 목적

1단계 탐색기로 모든 대사를 볼 수 있지만, **언제·어떻게·어떤 순서로** 일어나는지 알기 어렵다. 2단계는 게임에 플러그인을 넣어

1. **지금** 상호작용할 수 있는 이벤트와 각 조건의 충족 여부를 보여주고,
2. 실제로 본 대사·고른 선택지를 **회차·갈래별 시간순 기록**으로 남기며,
3. 모든 회차를 합친 기록으로 **아직 안 고른 선택지와 안 본 대사**를 찾아가게 한다.

이전에 고른 선택지를 명확히 보여줘서, 갈래·다음 회차에서 같은 선택을 반복하지 않게 하는 것이 핵심 사용 목적이다.

## 결정 사항 (사용자 확인)

- 게임은 같은 PC에서 `Game.exe`(NW.js)로 실행. 웹 배포판 제외.
- 플러그인은 **뷰어가 자동 설치/제거** (`plugins.js` 백업 후 등록).
- 통신은 **파일 방식**: 플러그인이 게임 폴더의 `rpg-viewer/` 아래에 기록(`log.jsonl`)과 현재 상태(`live.json`)를 쓰고, 뷰어가 0.5초마다 바뀐 부분만 읽는다. 뷰어가 꺼져 있어도 기록은 남는다.
- 회차 구분은 **자동**: 새 게임 = 새 회차. 세이브에 회차·갈래·기록 위치를 적어 두고, 로드하면 그 지점에서 갈라진 **새 갈래**로 기록한다. 플러그인 설치 전 세이브는 "출처 모를 세이브"로 새 회차.
- 본 것/고른 것 표시는 **모든 회차·갈래 합산**.
- 화면 배치는 **A안**: 상단 탭(`탐색기 | 기록 | 못 본 것 (N)`) + 사이드바 맨 위 "지금" 영역.
- 이전 선택 표시는 **뷰어에서만**. 게임 화면은 바꾸지 않는다.

## 범위

### 포함
- 게임 플러그인 `RPGViewerBridge.js` (MV/MZ 공용, 단일 JS 파일)
- 뷰어: 플러그인 설치/업데이트/제거, 기록·상태 폴링, 회차·갈래 트리, 기록 화면(접기 규칙), 진행도(본 대사·고른 선택지), 조건 실시간 판정, 못 본 것 목록, 탐색기 주석 표시
- 개발용 시뮬레이터: 게임 없이 브라우저 콘솔에서 기록·상태를 흘려 넣는 DEV 전용 훅

### 제외
- 게임 화면 안 표시(선택지 창 마킹 등)
- 웹 배포 게임, 하나의 exe로 압축 포장된 게임(설치 불가 안내만)
- 기록 편집·삭제·내보내기, 항목별 숨기기(실사용 후 판단)
- 플레이 없이 스위치 흐름으로 순서를 추정하는 보기(이후 단계)

## 아키텍처

```
[Game.exe]                                   [뷰어 (Chrome/Edge)]
 RPGViewerBridge.js                           ├ installer: plugins.js 등록/해제
  ├ 엔진 훅 → 기록 버퍼 → rpg-viewer/log.jsonl ─→├ LogTail: 0.5초 폴링, 늘어난 바이트만 읽기
  ├ 주기적 스냅샷 → rpg-viewer/live.json ───────→├ history: 회차·갈래 트리, 타임라인 접기
  └ rpg-viewer/meta.json (run/branch/seq 카운터)  ├ coverage: 본 대사·고른 선택지(+결과 요약)
                                               ├ evaluate: 조건 판정 (met/unmet/unknown)
                                               └ missing: 못 본 것 목록 + 필요한 조건
```

- 순수 로직은 `src/core/live/` (React·DOM 비의존, Vitest).
- 플러그인은 `plugin/RPGViewerBridge.js` (뷰어가 `?raw`로 번들해 설치 시 기록). 엔진 객체를 흉내 낸 가짜 환경에서 Vitest로 테스트.
- 화면 상태는 `LiveProvider`(React context)가 관리.

### 경로
- 게임 기준 폴더 `base`: 데이터 루트가 `www/data`면 `www`, `data`면 루트(``). 플러그인 쪽은 `path.dirname(process.mainModule.filename)`.
- `plugins.js`: `<base>/js/plugins.js`, 플러그인 파일: `<base>/js/plugins/RPGViewerBridge.js`
- 기록 폴더: `<base>/rpg-viewer/` — `log.jsonl`, `live.json`, `meta.json`, `plugins.js.bak`

## 데이터 계약

### 기록 (`log.jsonl`, 한 줄 = JSON 하나, 추가만 함)
모든 줄: `{ v: 1, seq, t, run, branch, type, ... }` — `seq`는 파일 전체에서 단조 증가, `t`는 ms epoch.
`src`는 1단계 `Location`과 같은 모양(`{source:"map",mapId,eventId,page}` 등), `cmd`는 그 페이지 명령 목록에서의 인덱스.

| type | 추가 필드 | 발생 |
|---|---|---|
| `branchStart` | `reason: "newGame"\|"load"\|"unknownSave"`, `parentBranch`, `fromSeq` | 새 게임, 로드 |
| `message` | `src, cmd, face, faceIndex, speaker, text`(원문, 줄은 `\n`) | 101 실행 |
| `scroll` | `src, cmd, text` | 105 실행 |
| `choices` | `src, cmd, options[]`(원문) | 102 실행 |
| `choice` | `src, cmd, picked`(항목 인덱스, 취소 분기는 `-2`) | 선택 확정 |
| `picture` | `src, cmd, pictureId, name` | 231 실행 |
| `transfer` | `mapId, x, y` | 장소 이동 완료 |
| `battle` | `phase: "start"\|"end"`, `troopId`, `result?: "win"\|"escape"\|"lose"` | 전투 시작/종료 |
| `state` | `src, cmd, changes[{kind:"switch"\|"variable"\|"selfSwitch", id, value}]` | 값 변경(프레임 단위로 묶음) |
| `save` / `load` | `slot` | 세이브/로드 |
| `error` | `message` | 플러그인 내부 오류 |

`run`/`branch`가 0인 기록(타이틀 화면 등)은 `error` 외에는 쓰지 않는다.

### 현재 상태 (`live.json`, 덮어쓰기 — 임시 파일에 쓴 뒤 rename)
맵·좌표, 실행 중인 이벤트, 현재 맵 이벤트별 현재 페이지(`-1` = 없음), ON 스위치 목록, 0이 아닌 변수, ON 셀프 스위치(`"mapId,eventId,A"`), 소지품·무기·방어구 개수, 소지금, 파티, 지금 떠 있는 선택지, 전투 중 여부, `run/branch/seq`, `pluginVersion`. 바뀌었을 때 최대 4회/초, 그리고 2초마다 heartbeat(`t` 갱신).

### 세이브 스탬프
`DataManager.makeSaveContents` 결과에 `rpgViewer: { run, branch, seq }`를 넣고, 로드 시 읽어 `branchStart{reason:"load", parentBranch: branch, fromSeq: seq}`(run 유지). 스탬프가 없으면 새 run의 `unknownSave`.

## 뷰어 기능

### 연결 상태 (상단 Badge)
- `● 연결됨 · 1회차 갈래 2` — `live.json`의 `t`가 5초 이내
- `○ 게임 꺼짐 · 마지막 기록 N분 전`
- `플러그인 미설치` — 클릭 시 설치 Dialog
- 설치 Dialog: 상태(미설치/설치됨/업데이트 필요/지원 안 함), 설치·업데이트·제거 버튼, 쓰기 권한 요청, Chrome/Edge 전용 안내. 제거는 `plugins.js`에서 **우리 항목만** 지우고 플러그인 파일 삭제(다른 플러그인 변경 보존). 백업은 첫 설치 때 한 번 만들어 두고 남긴다.

### 사이드바 "지금"
현재 맵 이름·좌표, 이 맵 이벤트와 현재 페이지: `●` 대사 있는 결정 키/접촉 페이지, `⚡` 자동 실행/병렬 처리, `○` 대사 없음(기본 숨김). 클릭 → 탐색기. "따라가기" 토글이 켜져 있으면 맵 트리가 현재 맵을 펼친다.

### 탐색기 주석
- 페이지 탭에 `지금` Badge(현재 맵의 그 이벤트가 그 페이지일 때)
- 조건 Badge 앞에 판정 아이콘: ✓ 충족 / ✗ 미충족 / ? 판정 불가(스크립트 등, 또는 게임 미연결)
- 본 대사: 흐린 체크 아이콘
- 선택지 항목: `✓ 1회차 갈래 1` Badge들, 없으면 `아직 안 고름`

### 기록 탭
- 맨 위 **지금 선택지** 카드(게임에 선택지가 떠 있을 때): 항목별로 고른 적 있는 회차·갈래와 **결과 요약**(그 선택 뒤 같은 갈래에서 처음 나온 대사 1줄, 스위치 변경, 이동, 최대 3개).
- 회차·갈래 선택(기본: 최신 갈래). 타임라인은 회차 시작부터 선택한 갈래까지의 경로(조상 갈래의 `fromSeq`까지 + 자기 기록).
- 항목: 대사(얼굴·화자·본문), `▶ 선택`, 🖼 그림, 🚪 이동, ⚔ 전투, 💾 세이브/로드. 갈래가 갈라진 지점에 `갈래 N개 ⇄`(클릭 시 해당 갈래로 전환). 대사·선택·그림 항목 클릭 → 탐색기의 해당 노드로 이동·강조.
- 접기 규칙:
  1. **반복 대화**: 같은 페이지에서 연속된 대사 묶음(에피소드)이 앞서 본 같은 페이지의 에피소드와 명령 번호 순서가 같고 선택이 없으면 `↻ 같은 대화 다시 봄 ×N`으로 접는다(인접한 반복은 N 누적).
  2. **상태 변경**: 대사·선택이 있는 에피소드와 같은 `src`면 그 아래에 표시. 나머지 연속된 상태 변경은 `⚙ 상태 변경 N개`로 접는다.
  3. **잦은 변수**: 기록 전체에서 60초 안에 10번 넘게 바뀐 변수는 기록 화면에서 제외(데이터는 유지).
  4. 대사 없는 병렬/자동 실행은 상태 변경 외에 남는 것이 없으므로 규칙 2로 처리된다.

### 못 본 것 탭
- **안 고른 선택지 항목**: 모든 페이지의 모든 선택지에서 한 번도 고르지 않은 항목(취소 분기 포함).
- **안 본 대사가 있는 페이지**: 선택지 분기 밖의 대사 중 안 본 것이 있는 페이지(라벨은 첫 안 본 대사).
- 각 항목: 위치(path), 필요한 조건 — 페이지 출현 조건(트리거 제외) + 감싸는 조건 분기(`아니라면`은 반대 판정) + 감싸는 선택지(`선택지 "…" 선택`, 판정 `?`) — 각각 ✓/✗/?, `지금 이 맵` Badge.
- 정렬: 지금 이 맵 → 조건 모두 충족 → 탐색기 순서. 필터 "지금 갈 수 있는 것만"(✗가 없는 것).
- 클릭 → 탐색기 해당 노드 이동·강조.

## 1단계 코드 변경
- `ScriptNode`의 `message`, `scroll`, `choices`, `picture`에 `cmd: number`(원본 명령 인덱스) 추가.
- `Condition`에 선택적 `test: ConditionTest`(판정용 구조) 추가 — `describe*`가 채운다.
- `GameFolder`를 확장한 `WritableGameFolder`(stat, 범위 읽기, 쓰기, 삭제, 쓰기 권한) — `DirectoryHandleFolder`, `MemoryFolder`가 구현. `FileListFolder`는 미지원(설치·실시간 비활성 안내).
- 라우트에 `#/history`, `#/missing` 추가.

## 오류 처리

| 상황 | 처리 |
|---|---|
| 쓰기 권한 거부 | 설치 Dialog에 "쓰기 권한이 필요해요". 탐색기·기록 읽기는 계속 |
| `plugins.js` 해석 불가 / 없음(압축 포장 게임) | 아무것도 쓰지 않고 "이 게임은 자동 설치를 지원하지 않아요" |
| 설치된 버전이 다름 | "업데이트" 버튼 |
| 기록에 깨진 줄 | 건너뛰고 개수를 상단 오류에 표시 |
| 명령 번호 어긋남(게임 업데이트) | 기록의 원문과 데이터의 원문이 다르면 진행도에서 제외(`uncertain` 집계), 기록 화면에는 "위치 불확실"로 표시하고 이동 링크 없음 |
| `live.json` 읽기 실패 | 다음 주기에 재시도 |
| 기록 파일이 줄어듦(삭제·초기화) | 처음부터 다시 읽음 |
| 게임 꺼짐 | "게임 꺼짐" 표시, "지금" 영역 비움, 판정은 `?` |
| 플러그인 내부 오류 | 모든 훅을 try/catch, 게임은 계속. `error` 기록(초당 1회 제한) |

## 테스트
- 플러그인: 가짜 엔진 전역 + 메모리 fs로 훅 동작(대사·선택·세이브/로드 갈래·새 게임·상태 묶음·스냅샷) 검증.
- 뷰어 core: 공용 픽스처 기록(`tests/fixtures/logs/sample-mz.log.jsonl`, `sample-mz.live.json`)으로 파싱, 갈래 트리, 타임라인 접기, 진행도, 판정, 못 본 것, 설치기, LogTail 검증.
- UI: 개발 시뮬레이터(`__rpgViewer.simulate…`)로 브라우저 확인 + 실제 게임 체크리스트(`docs/live-checklist.md`)를 사용자가 수행.
