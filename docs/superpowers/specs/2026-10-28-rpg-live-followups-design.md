# RPG Viewer — 2.1단계: 실사용 불편 보완 설계

작성일: 2026-10-28
선행: `2026-10-28-rpg-live-history-design.md`

## 배경 (사용자 피드백)
1. Brave에서 "게임 폴더 열기"가 업로드 방식으로 열려 설치가 막혔는데, 이유를 알 수 없었다.
2. 일부 기록이 "위치 불확실"로 빠진다. 대상 게임은 실행 중 번역문을 넣는 모드판이라 원문 비교가 실패하는 것으로 추정.
3. 현재 대사·선택지 **다음에 나올 내용**을 모아 볼 수 없다.
4. 특정 맵에 있을 때 **지금 조건으로 상호작용 가능하면서 아직 안 본 것**을 알고 싶다.

실제 게임 데이터·기록은 열어 보지 않는다. 검증은 기존 픽스처와 직접 만든 기록으로만 한다.

## 기능

### A. 폴더 접근 미지원 안내
- `showDirectoryPicker`가 없으면 시작 화면에 Alert: `이 브라우저는 폴더 접근을 지원하지 않아 읽기 전용으로 열려요. 기록 플러그인을 쓰려면 크롬·엣지를 쓰거나 Brave는 brave://flags/#file-system-access-api 를 켜 주세요.` (Brave가 아니면 Brave 문장 생략)
- 설치 Dialog의 미지원 안내에도 같은 이유 문장을 쓴다.

### B. 위치 확인 완화 + 원인 보기
- 기록을 데이터 위치에 연결하는 조건을 **구조 일치**로 바꾼다:
  - message: `list[cmd]`가 101, 얼굴 이름·번호 일치, 401 존재 여부가 기록 본문 비어 있음과 일치.
  - scroll: 105.
  - choices / choice: 102, 선택지 개수 일치(choice는 앞선 choices 기록이 있으면 그 개수).
- 구조는 맞고 본문만 다르면 연결하되 **실행 중 변경됨**(`changed`)으로 표시한다. 구조가 다르면 지금처럼 **위치 불확실**.
- 기록 탭의 `위치 불확실` / `실행 중 변경됨` Badge를 누르면 Popover로 **원인**과 **기록 문장 vs 데이터 문장**을 나란히 보여준다.

### C. "지금 이후" 카드
- 플러그인 1.0.2: 스냅샷에 `runningCmd`(실행 중 명령 인덱스)를 추가하고, `running`/`runningCmd`는 공통 이벤트 호출 등 **가장 안쪽 자식 인터프리터** 기준으로 보낸다.
- 기록 탭 맨 위(지금 선택지 위)에 카드: 실행 중 이벤트 경로 + **현재 대사부터 그 페이지 끝까지 남은 대본**(현재 블록의 나머지 → 바깥 블록의 나머지 순, 선택지는 모든 분기 펼침). 탐색기와 같은 렌더러를 써서 본 대사 ✓, 선택지 `✓ n회차 갈래 m` / `아직 안 고름`이 그대로 보인다. `탐색기에서 보기` 버튼.
- 플러그인이 1.0.1 이하라 `runningCmd`가 없으면 카드에 `플러그인을 업데이트하면 이후 대사를 볼 수 있어요`.

### D. 맵의 상호작용 가능 + 안 본 것
- 이벤트의 **현재 페이지**: 현재 맵은 스냅샷 값, 다른 맵은 RPG Maker 규칙(마지막 페이지부터 조건이 모두 충족되는 첫 페이지)으로 현재 상태에서 계산.
- 각 이벤트의 현재 페이지에 대해 `안 본 대사 수`(선택지 분기 밖)와 `안 고른 선택지 항목 수`를 센다. 하나라도 있으면 **새것**.
- 사이드바 "지금" 그룹: 이벤트마다 `새 대화` / `선택지 N` Badge, 그룹 헤더에 `안 본 것만` 토글.
- 사이드바 맵 트리: 상호작용 가능(●/⚡)하면서 새것이 있는 이벤트 수를 맵 옆에 `새 N` Badge로(게임 연결 중일 때만).

## 데이터 계약 변경
- `LiveSnapshot.runningCmd?: number | null` (선택 필드 — 구버전 플러그인 호환)
- `Coverage.changedSeqs: Set<number>`; `HistoryItem` record에 `changed: boolean`; `foldTimeline` opts에 `changedSeqs?`.

## 오류 처리
- 모든 core 함수는 예외를 던지지 않는다. 판정 불가 조건이 있으면 그 페이지는 "현재 페이지 아님"으로 보고 다음 페이지로 넘어간다(보수적).
- 플러그인은 기존 규칙(모든 훅 try/catch, 게임 영향 없음) 유지.

## 테스트
- core: 픽스처 + "번역된 본문" 합성 기록으로 changed/uncertain 구분, 불일치 설명, 현재 페이지 계산, 맵별 새것 집계, 남은 대본.
- 플러그인: 가짜 엔진에서 자식 인터프리터 기준 running/runningCmd.
- UI: 개발 시뮬레이터(`setLive({ running, runningCmd })`)로 확인. 실제 게임 확인은 사용자 테스트 데이터 준비 후.
