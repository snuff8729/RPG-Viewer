# 출시 전 화면 전체 다시 짜기 (정보 구조·배치·색) — 설계

## 왜

지금 화면은 기능이 생길 때마다 붙여 온 결과라, 같은 일을 하는 버튼이 여러 곳에 있고(백업 7곳, 치트·보조 4곳, 게임 설정 4곳), 화면마다 머리줄이 다르며(일반 화면은 버튼 7개, 플레이는 `⋯` 안에 숨김), 모든 상태가 같은 회색 배지라 무엇이 켜졌는지·무엇이 문제인지 한눈에 보이지 않는다. 플러그인 설치는 상태 글자(버튼처럼 안 보임)를 눌러야만 열리고, 다크 모드는 색만 있고 켤 방법이 없다. 휴대폰은 플레이 화면만 휴대폰 배치가 있고 나머지는 머리줄 버튼이 4줄로 쌓인다.

조사 원문: 코드 인벤토리·화면 점검(2026-11-01 세션).

## 사용자와 쓰임 (설계의 기준)

- **주 사용**: PC에서 게임을 하면서 옆(모니터 왼쪽 반, 가로 약 900~960px, 세로 전체)이나 휴대폰에 뷰어를 띄워 둔다.
- **자주 하는 일**: 맵을 보며 무엇과 상호작용할 수 있는지·해야 할 것이 무엇인지 확인, 게임 보조(배속·본 대사 넘기기·전투 건너뛰기 등)를 누름, 전투 때 이기기·도망·체력 조절, 가끔 치트(변수·아이템), 놓친 대사 읽기.
- **덜 하는 일**: 게임 없이 이벤트·대사 찾아보기, 못 본 것 찾기.
- **드문 일**: 플러그인 설치, 게임 위치 지정, 백업 관리, 휴대폰 연결, 게임 맞춤 설정, 진단.
- 휴대폰은 PC와 같은 비중(같은 구조, 같은 이름, 같은 순서).

## 설계 원칙

1. **빈도 순서 = 화면 순서.** 자주 하는 일은 늘 보이고 한 번에 누른다. 드문 일은 한 곳(관리)에 모은다.
2. **기능 하나에 집 하나.** 각 기능은 정해진 한 자리에서만 산다. 다른 곳에서는 그 자리로 "데려가는" 링크만 둔다.
3. **PC와 휴대폰은 같은 지도.** 이름·순서·아이콘이 같고, 넓이에 따라 펼쳐 보이는 정도만 다르다.
4. **색은 뜻이 있을 때만.** 바탕은 무채색(shadcn neutral). 색은 ① 연결 상태 ② 전투 ③ 맵 구역 ④ 경고·오류 ⑤ 켜짐(선택됨) 다섯 가지 뜻에만 쓴다.
5. **다음 할 일을 항상 말해 준다.** 빈 화면은 "왜 비었는지 + 누를 버튼 하나"로 채운다.
6. **UI는 shadcn 컴포넌트·공식 예시만.** 새 모양을 만들지 않고 조합한다.

## 1. 정보 구조 (전체 지도)

맨 위 단계는 세 곳뿐이다.

| 자리 | 하는 일 | 안에 있는 것 |
|---|---|---|
| **플레이** | 게임하면서 보는 곳 (기본) | 맵 · 보조 · 치트 · 읽기 (네 모듈) |
| **찾아보기** | 게임 없이 이야기·이벤트를 찾는 곳 | 이벤트 · 못 본 것 |
| **관리** | 가끔 하는 설정·관리 | 연결·실행 · 세이브 백업 · 휴대폰으로 보기 · 게임 맞춤 설정 · 진단 · 화면 · 게임 바꾸기 |

검색(Ctrl+K)은 어디서나 열린다(머리줄 돋보기).

| 지금 | 새 자리 | 비고 |
|---|---|---|
| 사이드바 "보기" 7개 | 머리줄 3곳 | 사이드바 없앰 |
| 플레이 | 플레이 | |

| 읽기 | 플레이 › 읽기 › `이야기` | |
| 기록 | 플레이 › 읽기 › `모든 기록` | 읽기와 한 자리, 위쪽 전환으로 고름 |

| 머리줄 게임 보조(팝오버)·치트(시트) | 플레이 › 보조·치트 | 덮는 창 없앰 |
| 머리줄 게임 설정(시트) | 관리 › 게임 맞춤 설정 | 다른 곳의 "바꾸기"는 이 자리로 데려감 |
| 플러그인 설치(상태 배지 클릭) | 연결 상태 단추 + 관리 › 연결·실행 | |
| 고정 핀, 다른 게임 열기 | 머리줄 게임 이름 메뉴 + 관리 › 게임 바꾸기 | |

옛 주소는 새 주소로 넘긴다(`#/here`→맵, `#/read`·`#/history`→읽기, `#/missing`→못 본 것, `#/diagnose`→관리 › 진단, 이벤트 페이지 `#/map/…`·`#/common/…`·`#/troop/…`는 찾아보기 › 이벤트 안에서 그대로).

## 2. 머리줄 (모든 화면 공통, PC·휴대폰)

**한 줄**: `[게임 이름 ▾] [연결 상태] · 지금 맵 이름` …… `[플레이 | 찾아보기 | 관리]` `[🔍]`

- **게임 이름 ▾**(DropdownMenu): 게임 고정/고정 풀기, 다른 게임 열기, 최근 게임 몇 개. 휴대폰 보기에서는 이름만(메뉴 없음).
- **연결 상태**(Button variant=outline, 색 점 + 짧은 말). 눌러 보이는 것: Popover로 지금 상태 한 문장 + **다음 할 일 단추 하나** + "관리에서 자세히". 상태와 단추:
  | 상태 | 점 색 | 말 | 단추 |
  |---|---|---|---|
  | 게임 켜짐(연결됨) | success(초록) | 게임 켜짐 | 없음 |
  | 확인 중·기다리는 중 | warning(호박) | 연결 확인 중 | — |
  | 게임 꺼짐 | 회색 | 게임 꺼짐 | **게임 실행** (서버 있을 때) |
  | 플러그인 없음 | warning | 플러그인 필요 | **플러그인 설치** |
  | 업데이트 필요 | warning | 업데이트 필요 | **업데이트** |
  | 지원 안 함 | 회색 | 기록 못 함 | 관리로 |
  게임 위치가 아직 없으면 실행 단추가 그 자리에서 위치 입력(GamePathDialog)을 먼저 연다.
- **세 자리 전환**: PC는 Tabs 모양 링크. 휴대폰은 머리줄에 넣지 않고 아래 탭 막대가 맡는다(4절).
- **관리 배지**: 오류·진단 주의·업데이트 필요가 있으면 "관리" 옆에 숫자 배지(warning/destructive).
- 휴대폰 머리줄: `[게임 이름] [연결 점+말] · 맵 이름` …… `[🔍]` 한 줄. 절대 두 줄로 쌓이지 않는다.

**둘째 줄 = 빠른 막대**(플레이에서만, 연결됐을 때만):

- **평소**: 고정한 보조 기능(기본: 배속, 본 대사 넘기기, 본 이벤트 자동 배속, 랜덤 전투 끄기, 전투 건너뛰기). 각 칸은 이름이 보이는 Toggle/ToggleGroup, 켜진 것은 primary로 채움. 넘치면 가로 스크롤(줄바꿈 금지).
- **전투 중**(live.inBattle): 막대 전체가 **전투 막대**로 바뀐다 — 바탕 destructive/10, 왼쪽 `⚔ 전투 중` 배지(destructive), 버튼 이기기 · 도망 · 지기(확인) · 적 체력 1% · 적 체력 100% · 내 체력 100%, 오른쪽 끝에 배속. 고정하지 않아도 전투 기능은 전투 중 늘 나온다(평소 막대에서는 전투 버튼이 사라짐). 쓸 수 없는 버튼(도망 불가 등)은 disabled + Tooltip 이유.
- 전투가 끝나면 평소 막대로 돌아온다(애니메이션 없이 즉시).

이유: 전투는 짧고 급하다. 사용자가 "어디 있지"를 찾지 않게, 상황이 바뀌면 화면이 먼저 바뀐다. 빨간 바탕은 "지금은 평소와 다른 상태"를 한눈에 알린다.

## 3. 플레이 (PC, 넓이 900px 이상)

```
┌ 머리줄 ───────────────────────────────────────────────┐
├ 빠른 막대 / 전투 막대 ────────────────────────────────┤
│ 맵 칸                         ┃ 도구 칸               │
│ ┌ 구역 칩(범례=거르개) ─────┐ ┃ [보조|치트|읽기]  ⧉   │
│ │      맵 그림             │ ┃                       │
│ │                          │ ┃  (탭 내용)            │
│ ├──────────── (끌어 크기) ─┤ ┃                       │
│ │ 다음 스토리 카드          │ ┃                       │
│ │ 해 볼 것 목록 (구역별)    │ ┃                       │
│ └──────────────────────────┘ ┃                       │
└───────────────────────────────────────────────────────┘
```

- 좌우 Resizable(크기 기억). 도구 칸 최소 340px, 접을 수 있음(접으면 맵 칸 전체).
- 900px 미만 창은 휴대폰 배치(4절)를 그대로 쓴다. "위아래로 쌓기" 배치는 없앤다.
- 각 모듈의 "따로 창으로 떼기"(⧉)는 유지.

### 맵 모듈 (지금 이 맵 + 이 맵 화면 + 사이드바 "지금" 합침)

- **구역 칩 줄**(맵 위): 안 본 내용 · 아이템 · 반복 · 이동 · 적 · 다시 가능 · 잠김 · 이야기 · 다 봄. 각 칩 = 그 구역 색 점 + 이름 + 개수. 누르면 그 구역 표시를 켜고 끔(지금 범례 팝오버의 일을 밖으로 꺼냄). 개수 0인 구역은 칩을 숨긴다. 벽 표시·적 피해서 길 찾기는 칩 줄 끝 `⋯` 메뉴.
- **맵 그림**: 칸을 채움. 확대·축소·맞춤·내 위치로는 그림 오른쪽 아래 작은 버튼 묶음.
- **아래 목록**(세로 Resizable, 접기 가능):
  1. **다음 스토리** 카드(맨 위 고정). 다음 목적지·조건 요약, "어떻게 하나요"(HowTo를 Sheet로).
  2. **해 볼 것 N**: 구역별 묶음(구역 색 점 제목). 줄 = 이벤트 이름 + 짧은 이유(안 본 대사·선택지 N·아이템…). 줄을 누르면 맵이 그 점으로, 맵 점을 누르면 목록이 그 줄로. 줄 오른쪽 `⋯`: 어떻게 하나요 / 찾아보기에서 보기.
  3. **다른 맵**(맨 끝): 해 볼 것이 남은 다른 맵 몇 곳과 개수. 누르면 찾아보기 › 못 본 것을 그 맵으로 거른 상태로 연다.
- **숫자는 하나**: 머리줄·탭 배지·목록 제목의 "해 볼 것 N"은 모두 같은 값(checklist.remaining)이다.

### 보조 모듈

상황별 Card 묶음, 위에서 아래로 자주 쓰는 순서:

1. **진행 속도** — 배속(×1 ×2 ×4 ×8), 이동 속도(×1 ×1.5 ×2 ×3)
2. **대사·이벤트** — 본 대사 자동 넘기기, 본 이벤트 자동 배속(+빠르기)
3. **전투** — 랜덤 전투 끄기, 전투 건너뛰기, 잡아 본 적만(전투 건너뛰기가 켜졌을 때만 보임, 들여쓰기), 그 아래 전투 중 버튼(이기기·지기·도망·적 체력)·내 체력. 전투 중이 아니면 전투 버튼은 disabled + "전투 중에만 쓸 수 있어요" 한 줄.
4. **세이브·백업** — 퀵 세이브·퀵 로드·세이브 창·로드 창, 퀵 세이브 칸, 지금 백업 · 마지막 백업으로 복원(서버 있을 때)
5. **단축키** — Collapsible(기본 접힘), 안에 단축키 편집·요약.

- 각 줄 오른쪽의 ☆ 대신 **Pin 아이콘 Toggle**(Tooltip "위쪽 막대에 고정"). 고정된 것은 채운 아이콘.
- 연결 안 됐으면 모듈 맨 위 하나의 안내(아래 "빈 화면 규칙"), 줄마다 반복하는 안내 글은 없앤다.

### 치트 모듈

탭 `변수 · 아이템 · 캐릭터 · 스위치` (PC·휴대폰 같은 순서. 사용자는 변수·아이템을 주로 쓰고 스위치는 거의 안 씀). 안쪽 기능은 그대로. "바꾼 것" 기록은 탭 아래 Collapsible. 위험 경고(빨강)는 유지하되 "지금 백업" 단추는 빼고 "관리 › 세이브 백업에서 백업할 수 있어요" 링크로.

### 읽기 모듈 (읽기 + 기록 합침)

- 맨 위 ToggleGroup `이야기 | 모든 기록`. 이야기 = 지금의 읽기(대사·선택·그림만 이야기처럼), 모든 기록 = 지금의 기록 타임라인(이동·전투·저장 포함).
- 도구 줄 하나: 갈래 고르기(BranchPicker), 목차(이야기에서만), **보기 설정** 단추(PC Popover / 휴대폰 Drawer — 같은 단추, 같은 내용: 전체 읽기/선택 흐름, 자동으로 맨 아래로, 음성 자동 재생, 그림 보기 / 기록에서는 종류 거르기·플러그인 명령·알림 문구).
- 거르기 칩(대사·선택·그림…)은 Toggle로, 켜진 것은 채움.
- 새 대사 N, ↓ 다음, 맨 아래로는 지금처럼 떠 있는 단추(PC·휴대폰 같음).

## 4. 플레이 (휴대폰·900px 미만 창)

```
┌ 머리줄 (한 줄) ───────────┐
├ 빠른 막대 / 전투 막대 ─────┤  ← 가로 스크롤 한 줄
│                            │
│   지금 탭 내용             │
│                            │
├────────────────────────────┤
│ 맵 │ 보조 │ 치트 │ 읽기 │ 더보기 │
└────────────────────────────┘
```

- 아래 탭 막대: `맵 · 보조 · 치트 · 읽기 · 더보기`. PC 도구 칸 탭(보조·치트·읽기)과 순서가 같다. 처음 열면 맵. 마지막 탭 기억. 새 선택지가 뜨면 읽기 탭에 점 배지(자동으로 탭을 바꾸지 않는다 — 맵을 보다가 갑자기 화면이 바뀌면 혼란스럽다).
- 맵 탭: 맵 그림이 화면을 채우고 구역 칩 줄은 위, 목록(다음 스토리·해 볼 것·다른 맵)은 아래에서 끌어 올리는 Drawer(손잡이에 "해 볼 것 N · 다음 스토리").
- 더보기 탭: 찾아보기·관리로 가는 목록(Item 목록) + 검색. 찾아보기·관리 화면에서도 아래 탭 막대는 그대로(더보기가 선택된 상태).
- 전투 막대는 어느 탭에서도 위에 붙어 있다.

## 5. 찾아보기

- 맨 위 ToggleGroup `이벤트 | 못 본 것`.
- **이벤트**: PC는 좌우 두 칸(왼쪽 트리 — 맵·공통 이벤트·전투 이벤트, 오른쪽 이벤트 화면). 휴대폰은 목록 → 이벤트 화면(뒤로 단추) 두 단계. 위치 표시(Breadcrumb)는 맵 이름을 자르지 않고 줄바꿈 허용.
- 이벤트 화면의 스위치·변수·아이템 참조(RefBadge)는 **칩 전체가 눌림**, 모양은 `outline` 배지 + 오른쪽 ↗, 손가락 커서·hover 밑줄. 눌리지 않는 표시는 ↗를 쓰지 않는다. 상호참조 Sheet 머리에 번호와 (연결됐으면) 지금 값.
- **못 본 것**: 거르기 ToggleGroup `이 맵 · 갈 수 있는 것 · 전체`(연결 안 됐으면 "갈 수 있는 것"은 disabled + 이유). 목록은 맵 → 이벤트 두 단계까지만 펼침(대사는 이벤트 줄 안에 미리보기).
- 진단 배너는 여기 없다.

## 6. 관리

PC: 왼쪽 섹션 목록(shadcn Sidebar 안쪽 메뉴 모양이 아니라 세로 버튼 목록 — settings 예시 모양), 오른쪽 내용. 휴대폰: 섹션 목록 → 내용(뒤로). 섹션마다 제목 + 한 줄 설명.

1. **연결·실행** — 플러그인 상태·버전·기록 크기, 설치/업데이트/제거(제거는 destructive, AlertDialog), 게임 폴더 위치(한 번 넣으면 실행·백업·휴대폰 보기·AI 맡기기가 같이 씀), 게임 실행.
2. **세이브 백업** — 지금 백업(이름), 자동 백업 스위치, 백업 목록 표(복원·삭제).
3. **휴대폰으로 보기** — 켜기 스위치, 기간, QR, 주소, 새 QR 만들기. 한 번도 안 켰을 때는 "기간이 끝났어요" 대신 "아직 켜지 않았어요".
4. **게임 맞춤 설정** — 지금 게임 설정 시트의 내용(스토리 진행 변수, 숨긴 그림, 이 게임 전용, 화면 그림 따라 그리기, 알림 문구 기록…). 각 항목 제목 + 한 줄 설명, 긴 문단은 Collapsible "자세히".
5. **진단** — 불러오기 오류(오류가 있으면 맨 위 destructive Alert), 진단 결과(상태 배지 색: 괜찮아요 success, 확인 필요 warning, 문제 destructive, 자동 처리 secondary), 추천 설정 모두 적용, AI에게 맡기기·AI 답변 풀어보기(설명 한 줄씩 붙여서).
6. **화면** — 테마 `시스템 · 밝게 · 어둡게`(기본 시스템).
7. **게임 바꾸기** — 다른 게임 열기, 고정.

휴대폰 보기(원격)에서는 PC에서만 되는 섹션(연결·실행, 세이브 백업, 휴대폰으로 보기, 진단의 AI 부분, 게임 바꾸기)을 목록에 회색으로 두고 누르면 "PC에서 해 주세요".

## 7. 빈 화면 규칙

- 연결이 필요한 모듈(맵·보조·치트·읽기)에서 연결이 없으면 모두 **같은 Empty 컴포넌트**: 제목 "게임과 연결되지 않았어요", 설명 한 줄, 단계 목록(① 플러그인 설치 ② 게임 실행)과 지금 단계의 단추 하나(연결 상태 단추와 같은 동작). 그 아래 보조 링크 "게임 없이 이야기 찾아보기 →".
- 게임을 처음 열었을 때: 연결돼 있으면 플레이, 아니면 플레이(위 안내가 보임). 
- 글은 모두 "-요" 말투.

## 8. 색 (토큰)

바탕·글·테두리는 shadcn neutral 그대로. 새 토큰(밝게·어둡게 둘 다, oklch, `@theme inline`에 연결):

| 토큰 | 뜻 | 쓰는 곳 |
|---|---|---|
| `--success` / `-foreground` | 잘 되고 있음 | 게임 켜짐 점, 진단 "괜찮아요", 복원 성공 |
| `--warning` / `-foreground` | 손이 필요함 | 플러그인 필요·업데이트, 연결 확인 중, 진단 확인 필요, 관리 배지 |
| `--info` / `-foreground` | 새로운 것 | 새 대사 N, 새 N |
| `--destructive`(기존) | 위험·오류·**전투** | 오류, 삭제·복원 확인, 전투 막대·배지 |
| `--primary`(기존) | 켜짐·선택됨·주 동작 | 켜진 Toggle/ToggleGroup 칸(채움), 기본 버튼 |
| `--section-*`(기존) | 맵 구역 | 맵 점, 구역 칩, 목록 제목 점 — **이 밖에서 쓰지 않음** |

- Toggle·ToggleGroup의 켜짐(`data-[state=on]`)은 primary 채움으로(지금은 연회색이라 켜졌는지 안 보임). components/ui 파일에서 한 번 바꾼다.
- disabled는 opacity로 흐리게 + 이유가 있으면 Tooltip.
- 화자 아바타 색이 빨강일 때 오류처럼 보이지 않게, 아바타는 section/destructive와 겹치지 않는 차분한 색 목록(chart 계열)을 쓴다.
- **다크 모드**: `<html class="dark">`를 테마 설정(시스템 기본, `prefers-color-scheme` 따라감)으로 켠다. 선택은 localStorage(기기별).

## 9. 말 (용어 하나로)

| 하나로 쓸 말 | 버릴 말 |
|---|---|
| 해 볼 것 N | 남은 것, 할 것 N개 남음, 지금 해 볼 것, 이 맵 전체 보기 |
| 보조 | 게임 보조 |
| 찾아보기 | 탐색기, 탐색 목록 |
| 이 맵 (거르기) | 지금 맵, 지금 이 맵 |
| 기록 플러그인 | 플러그인(단독), 브리지 |
| 세이브 백업 | 백업(제목으로 쓸 때) |
| 게임 맞춤 설정 | 게임 설정 |
| 위쪽 막대에 고정 | 즐겨찾기, ☆ |
| 게임 켜짐 / 게임 꺼짐 / 연결 확인 중 | 연결됨, ● 연결됨 등 |
| 게임과 연결되지 않았어요 | 게임이 연결되면 보여요, 게임에 연결하면 … 보여줘요 |

뜻이 어려운 말(출처 모를 세이브, N회차 갈래, 근거, 지금 ?)은 Tooltip 한 줄 설명을 붙이거나 쉬운 말로 바꾼다. 용어 목록은 코드에 한 파일(`src/ui/terms.ts`)로 두고 화면은 그걸 쓴다.

## 10. 그대로 두는 것

core 로직 전부, 플러그인, 단축키, 치트·보조·백업·휴대폰 공유·진단·리더의 기능 자체, 즐겨찾기 파일(favorites.json — "고정"이 같은 데이터를 씀), 모듈 따로 창. 배치·진입 경로·모양·말만 바뀐다.

## 11. 구현 단위 (순서대로, 단위마다 검토 후 다음)

1. **바탕**: 색 토큰(success/warning/info), 테마(시스템·밝게·어둡게) 공급자, Toggle 켜짐 모양, `terms.ts`, 공용 조각(ConnectionStatusButton + 상태 Popover, NotConnectedEmpty, SectionHeader).
2. **뼈대와 길**: 새 머리줄·세 자리·휴대폰 아래 탭 막대·더보기, 새 주소와 옛 주소 넘기기, 사이드바·옛 머리줄 버튼·옛 플레이 팝업·진단 배너 없애기, 관리 화면(일곱 섹션, 기존 다이얼로그·시트 내용을 섹션 안으로 옮김), 처음 여는 자리.
3. **플레이**: 빠른 막대·전투 막대, PC 맵 칸(구역 칩·목록·다른 맵)과 도구 칸, 보조 Card 묶음·고정 핀, 치트 탭 순서, 읽기+기록 합침과 보기 설정 통일, 이 맵 화면 합침, 휴대폰 맵 Drawer.
4. **찾아보기**: 이벤트 두 칸/두 단계, 참조 칩, 못 본 것 거르기·단계 줄이기, 검색(화자 표시·결과 수·한글 강조 깨짐 고침).
5. **다듬기**: 말 맞추기 전체 훑기, 시작 화면(최근 게임 목록·어떤 폴더를 고르는지 한 줄·"이 앱으로 할 수 있는 것" 세 줄), README 사용법 갱신.
