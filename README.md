# RPG Viewer

RPG Maker MV/MZ 게임 폴더를 브라우저에서 열어, 모든 이벤트의 대사·선택지·그림·상태 변화를 읽기 좋은 스크립트로 보여주는 로컬 웹 앱입니다.

## 실행 방법

```bash
npm install
npm start
```

크롬 또는 엣지에서 http://localhost:5173 을 열고 **"게임 폴더 열기"** 를 눌러 게임 폴더(MV/MZ 프로젝트 루트)를 선택합니다.

- 평소에는 **`npm start`** 로 여세요. 켤 때마다 뷰어를 새로 빌드한 뒤(몇 초) 빠른 실행용으로 엽니다. 기록이 긴 게임에서도 PC·휴대폰 화면이 훨씬 가볍습니다.
- `npm run dev`는 뷰어를 고치는 개발용입니다(코드를 고치면 바로 반영되지만 더 무겁습니다).
- 두 방법 모두 같은 주소(5173)를 쓰므로 설정·읽은 위치·휴대폰 주소(QR)가 그대로 이어집니다. 5173을 이미 다른 창이 쓰고 있으면 5174처럼 다음 번호로 열립니다(창에 나온 주소를 여세요).
- 아래에서 "로컬 뷰어 서버가 있을 때만"이라고 한 기능(게임 실행·백업·휴대폰으로 보기·가린 사본)은 `npm start`와 `npm run dev` 모두에서 동작합니다.

## 지원 범위

- RPG Maker **MV / MZ**만 지원합니다 (XP/VX/VX Ace 미지원).
- 맵 이벤트, 공통 이벤트, 전투 이벤트를 읽습니다.
- 암호화 이미지 `.rpgmvp`, `.png_`를 복호화해 표시합니다.
- 데이터 JSON까지 암호화된 게임은 미지원입니다.
- 플러그인 명령은 해석하지 않고 원문 그대로 표시합니다.

## 사용법

- **사이드바**: 맵과 공통/전투 이벤트를 탐색합니다.
- **"대사 없는 항목 표시" 토글**: 대사가 없는 이벤트도 목록에 포함할지 정합니다.
- **Ctrl+K**: 대사·선택지·화자 이름을 검색합니다. 결과를 고르면 해당 페이지로 이동해 그 줄을 강조합니다. (macOS는 Cmd+K)
- **스위치/변수 Badge 클릭**: 해당 스위치·변수를 참조하는 위치 목록(상호참조)을 엽니다.
- **"다른 게임 열기"**: 상단 오른쪽 버튼으로 시작 화면으로 돌아가 다른 게임 폴더를 엽니다.
- **"게임 실행"**: 폴더 열기로 연 게임을 뷰어에서 바로 실행합니다. 처음 한 번 게임 폴더 경로(탐색기에서 Shift+오른쪽 클릭 → "경로로 복사")를 붙여 넣으면 게임마다 기억합니다. 뷰어를 `npm start`(또는 `npm run dev`)로 열었을 때만 동작합니다(로컬 뷰어 서버가 `Game.exe`를 실행).
- **"백업"**: 세이브 폴더 전체(공용 데이터 `global.rpgsave`·`config.rpgsave`, 플러그인이 그 폴더에 쓴 파일 포함)를 통째로 `<게임 폴더>/rpg-viewer/backups/`에 남기고 되돌립니다. `지금 백업`으로 직접 남기고, `자동 백업`(기본 켜짐)은 게임 실행 직전과 게임이 저장한 뒤(실행 중 15초마다 확인, 최대 2분에 한 번)에 남깁니다. 복원하면 먼저 지금 상태를 「복원 전」 백업으로 남기고, 게임이 실행 중이면 강제로 끈 뒤 복원하고 다시 실행합니다. 자동 백업은 최근 30개, 「복원 전」은 최근 10개만 두고 수동 백업은 지우지 않습니다. "게임 실행"과 같이 로컬 뷰어 서버가 있을 때만 동작합니다.

## 휴대폰·태블릿으로 보기

PC에서 게임을 하면서, 같은 와이파이에 있는 휴대폰이나 아이패드로 플레이 화면(읽기·맵)을 볼 수 있습니다. 뷰어를 `npm start`(또는 `npm run dev`)로 열었을 때만 동작합니다.

- **켜기**: 상단의 **"휴대폰으로 보기"** 를 눌러 스위치를 켜고, 휴대폰 카메라로 QR을 찍습니다. 처음 켤 때 Windows 방화벽 창이 뜨면 **'개인 네트워크' 허용**을 눌러 주세요.
- **허용 기간**: 1일 / 7일 / 30일 중에서 고릅니다(기본 7일). 그 기간 동안은 PC나 뷰어를 다시 켜도 같은 QR·주소가 그대로 열립니다. 휴대폰에서 연 뒤 Safari **공유 → 홈 화면에 추가**를 해 두면 다음부터 한 번에 열립니다.
- **보는 게임**: PC 뷰어에서 연 게임을 따라갑니다. PC에서 다른 게임을 열면 휴대폰도 잠시 뒤 그 게임으로 바뀝니다.
- **휴대폰에서 할 수 있는 것**: 읽기·맵·스토리 보기와, 위쪽 **게임 도구**(렌치 단추)의 **게임 보조**(배속·본 대사 넘기기·전투 이기기 등)·**치트**·**게임 설정**. 바꾼 것은 PC 뷰어와 같은 파일(게임 폴더의 `rpg-viewer/control.json`·`rpg-viewer/addons.json`)에 저장되어, PC와 휴대폰 어느 쪽에서 바꿔도 몇 초 안에 양쪽에 똑같이 보입니다. 한쪽에서 바꾼 설정이 다른 쪽 변경을 지우지 않습니다.
- **휴대폰에서 할 수 없는 것**: 게임 실행·휴대폰으로 보기 켜고 끄기·백업·플러그인과 게임 전용 확장 설치·제거·기록 고치기(갈래 지우기)·다른 게임 열기. 이것들은 PC에서 해 주세요.
- **끄기**: 스위치를 끄면 그 자리에서 모든 휴대폰 연결이 끊깁니다(다시 켜면 새 QR). **"새 QR 만들기"** 는 켠 채로 지금까지 연결한 휴대폰만 끊습니다.
- 같은 공유기 안쪽(로컬 네트워크) 기기만 들어올 수 있고, QR에 든 비밀 값이 있어야 열립니다. 켜짐 상태와 비밀 값은 사용자 폴더의 `.rpg-viewer/share.json`에 저장됩니다.

## AI에게 맡길 때 가린 사본 쓰기

게임 문제를 AI(에이전트)에게 맡길 때, 게임 속 글을 AI가 보지 않게 하려면 **가린 사본**을 만들어 그 폴더만 넘겨 주세요. 게임 원본은 읽기만 하고 절대 바꾸지 않습니다. 명령어는 필요 없습니다.

1. 게임을 열고 **`게임 진단`** 화면에서 **`AI에게 맡기기`** 를 누릅니다.
2. "어떤 문제가 있었나요?"에 문제를 한두 줄 적고(안 써도 됨) **`가린 사본 만들기`** 를 누릅니다.
3. 사본은 `문서\RPG-Viewer-Masked\` 아래에 생깁니다(폴더 이름의 게임 이름도 가려짐). 창에 나온 **Claude Code에 붙여 넣을 말**을 복사해 그대로 붙여 넣으면 됩니다.
4. 창에 "가려지지 않은 단어가 N곳 남았어요"가 나오면, 사본의 `MASK-WARNINGS.md`를 확인하기 전에는 보내지 마세요.

- 사본에서는 게임 글이 `T_1a2b3c4d5e6f70` 같은 **토큰**으로 바뀝니다. 같은 글이면 어디서나 같은 토큰이라 AI가 흐름은 따라갈 수 있습니다. 그림·소리 파일은 이름만 있는 빈 파일입니다. 사본 안에는 `AI-README.md`(AI에게 주는 안내)와 `REPORT.md`(문제 설명 + 자동 진단, 같은 방식으로 가림)가 있습니다.
- AI 답변에 토큰이 섞여 있으면 **`AI 답변 풀어보기`** 에 붙여 넣으세요. 이 게임의 원래 글로 바꿔 보여 줍니다(이 PC 안에서만).
- AI가 만든 어댑터에는 토큰이 그대로 들어 있어도 됩니다. 뷰어가 게임에 맞출 때·게임 쪽 확장을 설치할 때 원래 글로 바꿉니다. 이 게임에서 찾지 못한 토큰이 있으면 설치 화면에 알려 줍니다.
- 뷰어를 `npm start`(또는 `npm run dev`)로 열었을 때만 쓸 수 있고, 휴대폰 보기에서는 쓸 수 없습니다.

개발자용: 같은 일을 명령줄로도 할 수 있습니다 — `npm run mask -- "<게임 폴더>" --out "<빈 폴더>" [--note "..."]`, `npm run unmask -- "<게임 폴더>" <파일...>`.

## 개발

```bash
npx vitest run               # 테스트
npm run build                # 프로덕션 빌드 (타입 체크 포함)
node scripts/make-fixture-images.mjs   # 테스트 픽스처 암호화 이미지 재생성
```

개발 모드(`npm run dev`)에서는 브라우저 콘솔에서 테스트 데이터를 바로 열 수 있습니다.

```js
await __rpgViewer.openFixture("sample-mz")
```

## 실시간 연결과 플레이 기록

게임에 기록 플러그인을 설치하면, 게임을 플레이하는 동안 대사·선택 기록과 현재 상태를 뷰어에서 볼 수 있습니다. 크롬/엣지에서 "게임 폴더 열기"(시작 화면 버튼)로 연 게임만 지원하며(폴더 쓰기 권한 필요), 압축 포장된 게임은 `지원하지 않아요`로 표시됩니다.

- **설치**: 상단의 `플러그인 미설치` 배지를 눌러 "기록 플러그인" 창을 열고 **설치**를 누릅니다. 폴더 쓰기 권한을 허용해야 합니다. 설치 후 게임을 다시 시작하면 기록을 시작합니다.
- **연결 표시**: 게임을 실행하면 상단 배지가 `● 연결됨`으로 바뀌고, 게임을 끄면 `○ 게임 꺼짐 · 마지막 기록 N분 전`이 됩니다.
- **탭**: 탐색 목록에 **기록**(플레이한 순서의 타임라인, 분기·갈래 전환 포함)과 **못 본 것**(아직 보지 못한 대사 목록) 탭이 생깁니다. 게임이 실행 중이면 사이드바에 "지금" 그룹도 나타납니다.
- **게임 창 단축키**(플러그인 1.22.0 이상, 상단 **게임 보조**의 `단축키`에서 바꾸거나 끌 수 있고 Ctrl·Shift·Alt 조합도 됩니다. 조합 키는 조합 그대로일 때만 듣습니다):
  - 진행: `F6` 배속(×1→×2→×4→×8), `Ctrl+F6` 본 이벤트 자동 배속 빠르기(×2→×4→×8), `F7` 본 대사 자동 넘기기 켜고 끄기, `Ctrl+F7` 본 이벤트 자동 배속 켜고 끄기
  - 전투(전투 중만): `F10` 이기기, `F11` 지기, `Ctrl+F10` 도망, `Ctrl+Home` 적 체력 100%, `Ctrl+End` 적 체력 1%(살아 있는 적 전원, 1%는 적을 쓰러뜨리지 않음 — 플러그인 1.23.0. **게임 보조**의 전투 칸에도 같은 단추가 있습니다)
  - 체력(맵·전투): `Home` 내 체력 100%, `End` 내 체력 1%
  - 세이브: `Ctrl+S` 퀵 세이브, `Ctrl+L` 퀵 로드(두 번 누름), `Ctrl+Shift+S` 세이브 창, `Ctrl+Shift+L` 로드 창
  - 백업(PC 뷰어가 켜져 있을 때): `Ctrl+B` 세이브 백업, `Ctrl+Shift+B` 마지막 백업으로 복원(두 번 누름)
  - 게임이 쓰는 키(방향키·Enter·Space·Z·X·Esc·F2~F5·F8·F9 등)와 게임 창·Windows가 쓰는 조합(Ctrl+R·Ctrl+W·Ctrl+Q·Ctrl+Shift+I·Alt+F4 등)은 고를 수 없습니다. 예전에 기본값 그대로 두었던 단축키는 새 기본값으로 바뀌고, 직접 바꾼 단축키는 그대로 남습니다.
- **제거**: 같은 창의 **제거**를 누르면 `js/plugins.js`의 플러그인 항목과 플러그인 파일(`js/plugins/RPGViewerBridge.js`)만 지워집니다. `rpg-viewer/` 폴더와 백업은 그대로 남습니다.
- **게임 폴더의 `rpg-viewer/`**:
  - `log.jsonl`: 플레이 기록(한 줄에 한 건)
  - `live.json`: 현재 상태 스냅샷 (`live.json.tmp`는 쓰는 도중의 임시 파일)
  - `meta.json`: 플러그인이 쓰는 진행 메타 정보
  - `plugins.js.bak`: 설치 전 `plugins.js` 백업(처음 설치할 때 한 번만 만듦)
- **주의**: 세이브 미리보기 등을 위해 `DataManager.extractSaveContents`를 직접 호출하는 다른 플러그인이 있으면 기록에 불필요한 갈래가 생길 수 있습니다.

실제 게임으로 확인할 항목은 [docs/live-checklist.md](docs/live-checklist.md)에 있습니다.

### 개발용 시뮬레이터

게임 없이 `npm run dev` 콘솔에서 기록·상태를 흘려 넣을 수 있습니다. 먼저 `openFixture`로 픽스처(메모리 폴더, 쓰기 가능)를 열어야 합니다.

```js
await __rpgViewer.openFixture("sample-mz")
await __rpgViewer.simulateFixtureLog()   // 픽스처 기록·상태를 rpg-viewer/에 씀
await __rpgViewer.appendLog({ type: "..." })  // 기록 한 줄 추가
await __rpgViewer.setLive({ mapId: 1 })       // live.json 갱신(인자 없으면 하트비트)
```
